## 🚀 Featured Work

### [Churn Prediction with Explainable AI](https://github.com/manasi210772/Churn-Prediction-with-XAI)
> XGBoost churn classifier achieving **99% accuracy**, with SHAP-powered explainability deployed as a Flask web application.

`XGBoost` `SHAP` `Flask` `scikit-learn` `Python` `HTML/CSS/JS`

**Why it matters:** Goes beyond a Jupyter notebook — it's a full ML pipeline with a working front-end that explains *why* each prediction was made. Directly addresses the "black box" problem in enterprise ML.

---

### [SpeechUI Nakshatra — AI Voice Assistant for Cognitive Health](https://github.com/manasi210772/SpeechUI_Nakshatra)
> A bilingual (English & Hindi) voice assistant that conducts a conversational cognitive health screening using real-time speech recognition and an LLM-powered scoring engine.

`React` `Vite` `Flask` `Groq (LLaMA 3.3 70B)` `Web Speech API`

**Why it matters:** Built specifically for elderly users with early cognitive decline — every design decision (large fonts, voice-first interaction, minimal clutter) is intentional. Combines real-time speech I/O, an LLM evaluation layer, and accessible UI design into one cohesive product, built for a hackathon.

---

### [Stock Price Prediction — LSTM, GA Optimization & Streamlit Apps](https://github.com/manasi210772/Stock-Prediction-with-LSTM-and-GA)
> A progression of stock forecasting projects: a from-scratch **PyTorch LSTM** with **Genetic Algorithm** hyperparameter optimization, plus deployed **Streamlit** web apps for interactive next-day price prediction.

`PyTorch` `Genetic Algorithm` `Streamlit` `yfinance` `NumPy` `Matplotlib`

**Why it matters:** The LSTM is implemented from scratch — not a high-level wrapper — and the GA tunes sequence length, hidden size, layers, dropout, and learning rate, showing real understanding of model architecture. These ideas are then carried into interactive Streamlit apps ([stock-prediction-with-streamlit](https://github.com/manasi210772/stock-prediction-with-streamlit), [stock-price-prediction](https://github.com/manasi210772/stock-price-prediction)) that turn the research into something a non-technical user can actually use.

---

### [Mini Authentication App — Full-Stack MERN](https://github.com/manasi210772/Website)
> A full-stack authentication system built from scratch with React, Express, MongoDB, and Node.js — covering signup, login, password hashing, and a protected dashboard.

`React` `Vite` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `bcrypt`

**Why it matters:** Demonstrates core software engineering fundamentals end-to-end — frontend/backend communication, REST API design with Axios, database integration via Mongoose, and secure password handling with bcrypt. A solid signal of full-stack readiness beyond the ML/data-science work above.
