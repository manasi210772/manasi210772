`XGBoost` `SHAP` `Flask` `scikit-learn` `Python` `HTML/CSS/JS`

**Why it matters:** Goes beyond a Jupyter notebook — it's a full ML pipeline with a working front-end that explains *why* each prediction was made. Directly addresses the "black box" problem in enterprise ML.

### 📈 [LSTM + Genetic Algorithm Stock Predictor](https://github.com/manasi210772/Stock-Prediction-with-LSTM-and-GA)
> Next-day stock price prediction using a **custom-built PyTorch LSTM**, with a Genetic Algorithm for automatic hyperparameter optimization.

`PyTorch` `Genetic Algorithm` `yfinance` `NumPy` `Matplotlib`

**Why it matters:** The LSTM is implemented from scratch — not a high-level wrapper. The GA optimization tunes sequence length, hidden size, layers, dropout, and learning rate, demonstrating real understanding of model architecture.

**Why it matters:** A niche, self-motivated project that shows curiosity beyond standard ML templates — and the ability to translate a low-level algorithm directly into a usable web application.
